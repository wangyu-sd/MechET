Implemented eigendecomposition remediation
-------------------------------------------
The current src/features/extra_features.py contains the following remediation:

1. It removes the original shared dummy-node diagonal block from the matrix sent
   to the eigensolver.
2. It extracts each graph's real-node Laplacian using node_mask.
3. It decomposes graphs individually instead of calling a batched eigh on padded
   matrices.
4. It uses float64 and explicitly re-symmetrizes every real-node submatrix.
5. It rejects empty graphs and non-finite Laplacian values with clearer errors.
6. It retries a CUDA failure with CPU LAPACK.
7. If CPU LAPACK also fails, it retries with a diagonal jitter up to 1e-10.
8. It pads the resulting eigenvalues/eigenvectors back to the original batch
   shape so the downstream feature dimensions remain unchanged.

The graph definition and selected features were not changed: adjacency is still
constructed from E_t[..., 1:], the Laplacian is still L = D - A, and the model
still consumes the connected-component count, the first five nonzero
eigenvalues, the non-largest-component indicator, and the first two nonzero
eigenvectors.

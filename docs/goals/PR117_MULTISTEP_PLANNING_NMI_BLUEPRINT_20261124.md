## 1. 现状诊断与战略转向（为什么必须立刻切换）

### 1.1 前期短步训练（`round-000204`）的实测定位
- 已安全停止的 8×H20 Streaming 任务（`meteor_mechet_pr116_adaptive_streaming_8h20_20261124_12`，最新完整落盘 `round-000204`，`complete_sha256: 4cc1dfed79ebca034d2b7d45b2325559612333fb3c2a521398191914a62d3a9f`）累计覆盖 26,112 个 D3 目标。
- **关键诊断**：
  1. **80% 算力耗在短步片段**：约 80% 目标在 1–2 个 `FINISH` 即截断为 `segment_complete_continuation_unknown`，本质是局部短步适应/蒸馏，而非面向完整 AND/OR 闭合的多步规划后训练；
  2. **探索严重枯竭**：`stepwise.temperature = 0.25` 叠加尖锐的 SFT 基座导致策略熵仅 `0.0066`，同状态 K=2/K=4 分叉重复率极高；
  3. **抽检证实“撞库水分”与 1 步占比过高**：对 `round-000192` 256 个目标的实测抽检显示，29 条 `stock_solved` 中 **76%（22/29）仅为 1 步反应**，≥3 步仅 2 条（6.9%），且闭合路线内单步双向 PR18 得分最低低至 `-1.000`（p25 = `-0.036`）。
- **资产保留**：`round-000204` 完整保留，直接作为论文四阶消融中的 **“短步局部适应（Short-Horizon Adaptation）”** 对照基线。

### 1.2 对齐 2025–2026 前沿逆合成规划的 4 大核心瓶颈

吸收 **FlowER (*Nature 2025*)** 的“物理守恒 + 组合泛化”叙事与 **RetroChimera (*Nature 2026*)** 的“化学可信度优先（URSA `Solv-2`）+ 分层难度 + 复杂案例深度剖析”实验设计，将 Retro-E 精准锚定在现有反应级黑盒模型（RetroChimera / DirectMultiStep / R³ / RetroAgent / RetrOrchestrator）无法解决的 **4 大前沿瓶颈**：

| 前沿核心瓶颈 | 反应级黑盒模型的局限 | Retro-E（逆向电子流规划）的破局机制 |
|---|---|---|
| **1. 高闭合率 ≠ 高化学可信度**<br>（URSA Expert 上 RetroChimera `Solv-0=99% → Solv-2=32%`，DMS `85% → 15%`） | 黑盒字符串/模板在搜索期不校验原子/电子守恒与正向可逆性，大量路线死于隐式副反应与价键幻觉。 | **可执行电子流状态机 + 在线双向 CRN-JEPA (PR18)**：每步编译为严格电子守恒基元程序并同步验证逆向+正向可逆一致性，拉高 `Solv-2 / Solv-0` 留存率与 `MV-Solv`。 |
| **2. 局部机理可行 ≠ 全局多步可合成**<br>（Local–Global 错位） | 单步模型与短步微调只优化局部似然；实测局部打分器在 >60% 关键分叉点上偏好下游成环或死路的分支。 | **长程多步规划后训练（高纯度 RFT/DPO + 100% 完整路线 ReFIT-PO）**：将终局 AND/OR 闭合结果反传至同电子态竞争动作，逆转局部短视偏好。 |
| **3. 稀有/未见组合与复杂天然产物（OOD / CbyD）泛化崩塌** | 模板库覆盖有限；SMILES 生成在稀有组合与复杂多环手性骨架上迅速失真。 | **基元电子流的组合泛化**：有机极性反应由有限基元电子推动组合而成，在稀有/未见组合与 CbyD 关键战略断键上天然更具泛化性。 |
| **4. 粗粒度反应级搜索与失败死循环** | 必须等完整前体生成后才分叉，遇错丢弃整步重来；单步 SFT 遇错后 21/22 次重复同一错误。 | **亚反应级电子态分叉 + 冲突导向回跳**：在未完成反应态保留竞争电子态，遇祖先成环/死路精准回跳至责任电子步并切换路线。 |

## 2. 面向现实应用的奖励函数设计（Mechanistically-Gated Long-Horizon Reward）

为解决原子守恒体系下的“合法但化学离谱”撞库 Reward Hacking，并直接回应实验室落地最关心的 **化学选择性/副反应、立体手性保持、步骤经济性（LLS）、抗断供与多样性** 等现实瓶颈，将奖励函数定型为：

$$R(\tau) = \underbrace{\mathbb{I}[\text{all-stock closed}] \cdot G_{\text{mech}}(\tau) \cdot G_{\text{stereo}}(\tau) \cdot \phi_{\text{LLS}}(\tau)}_{\text{机理与现实可用性门控的终局规划回报}} + \underbrace{R_{\text{discharge}}(\tau)}_{\text{受终局约束的库存消解进度}} - \underbrace{C_{\text{conflict}}(\tau)}_{\text{成环与重复加倍惩罚}}$$

1. **木桶机理门控 $G_{\text{mech}}(\tau)$（直击选择性与副反应）**：
   - 取整条闭合路线中最弱一步的双向/正向 PR18 得分 $q_{\text{mech}}(\tau) = \min_{e \in \tau} s_{\text{bidir}}(e)$ 与正向可逆重放分 $\min_{e \in \tau} s_{\text{fwd}}(e)$；
   - 全步正向可逆且 $q_{\text{mech}} \ge \tau_{\text{high}}$ 时 $G_{\text{mech}} = 1.0$（若额外匹配参考路径给予温和加成 $+0.2$）；存在低分/正向不可逆步（如 $q_{\text{mech}} < 0$）时强衰减至 $0.2$ 或 $0$，杜绝撞库作弊。
2. **旁观手性守恒门控 $G_{\text{stereo}}(\tau)$（RDKit 零成本硬校验）**：
   - 核验未参与电子重排的旁观手性中心（spectator stereocenters）是否完整保持构型；无故丢失或意外翻转手性标签则衰减终局分。
3. **步骤经济性与汇聚性因子 $\phi_{\text{LLS}}(\tau)$**：
   - 基于最长线性步数（LLS）与树形汇聚度做温和调制，在同等闭合质量下鼓励汇聚型拆解、抑制冗长直链与无意义保护-脱保护绕圈。
4. **受终局约束的库存消解进度 $R_{\text{discharge}}(\tau)$ + 保守电子流归因**：
   - 合法、无环且双向 PR18 达标的 `FINISH` 若成功消解出真实库存前体并实质降低剩余非库存复杂度，给予有界进度分（如 `+0.10`/步，上限 `0.30`，终局失败时衰减/回滚），并通过 `route_flow_credit.py` 保守分摊至因果 `FLOW`。
5. **分级冲突惩罚 $C_{\text{conflict}}(\tau)$**：
   - 普通语法/缺键拒绝 `-0.10`；祖先成环（`ROUTE_CYCLE`）与同状态重复报错加倍惩罚 `-0.25`。
6. **同状态反事实信用（ReFIT-PO）**：
   - 在完全相同的中间电子态 $s$ 上，使用上述门控后的完整终局回报 $R(\tau)$ 计算语义去重后的组内相对优势 $A_{\text{ReFIT}}(s, a_i) = R(\tau_i) - \bar{R}(s)$。

## 3. 两阶段高纯度多步规划后训练方案（宁缺毋滥）

### Stage 1：严格质控的多步规划与反事实冷启动（8×H20，~3–4 小时）
- **数据严选**（从 PR116 27,136 目标 + 历史 PR110/D3 存档合并过滤，绝不盲目灌入 1 步撞库数据）：
  1. **高纯度多步正样本（RFT）**：仅保留 `depth ≥ 2`、`all-stock closed`、且 `min_pr18 ≥ 0` + 旁观手性保持的完整路线，按深度 `2 / 3 / 4+` 加权，彻底剔除 1 步送分题；
  2. **同状态反事实偏好对（DPO）**：精确同电子态下，`chosen` = 机理达标的完整闭合分支，`rejected` = 最终成环 / 拒绝 / 不可闭合分支；
  3. **失败回溯恢复样本**：记录报错/成环后换路最终闭合的真实恢复片段；
  4. **原始 FlowER SFT 锚点（25%–30%）**：稳住单步原子守恒语法，防灾难性遗忘。
- **联合目标**：$\mathcal{L} = \mathcal{L}_{\text{SFT}}(\text{高纯度多步路线} + \text{SFT 锚点}) + \lambda \mathcal{L}_{\text{DPO}}(\text{同状态反事实对})$。

### Stage 2：100% 完整路线 + 高探索长程 ReFIT-PO（8×H20，~14–16 小时）
- **课程目标池**：从 D3 149,092 目标中过滤掉参考深度 = 1 的简单题，仅在 **深度 2–5 步（线性 + 汇聚 + 长链）** 目标池上运行 **100% `lane="full"`**（彻底取消 80% 短片段）；
- **超参修正**：
  - `temperature`: `0.25 → 0.80`（打破低熵死锁，激活同状态分支多样性）；
  - `learning_rate`: `2e-6 → 1e-5`，`kl_beta`: `0.02 → 0.01`；
  - 放大并发目标池，提升 8×H20 的实际 KV Cache 与 decode batch 利用率；
- **步数预算与验收**：运行 **64–96 步**，每 16–32 步落盘并用 **512 clean VALID**（严格 target-disjoint 内部验证集）跟踪 `多步闭合率 (depth≥2)`、`机理门控闭合率`、`平均最小 PR18 分`，锁定最终主模型 **`Retro-E-Plan`**。

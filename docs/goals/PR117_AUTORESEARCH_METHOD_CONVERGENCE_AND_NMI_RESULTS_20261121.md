State: current exact atom-mapped electronic mixture, accepted native electronic actions in current reaction, full AND/OR route occurrence graph, root, exact ancestor molecules, all pending precursor obligations, stock leaves, failed completed reaction outcomes and authentic history receipts.

Chemistry decisions: ONLY existing Qwen actor emitting IMPORT, FLOW, FINISH. The route controller may allocate search work or restore an authentic checkpoint but can NEVER invent precursor SMILES, executable electron actions, hidden training labels, or false stochastic likelihoods.

Mechanism 1 — electron-first reaction frontier: Default K1; only at the root reaction (and one genuinely difficult descendant if budget permits) sample K2/rare K3 authentic distinct early FLOW proposals under the same prompt. Execute temporarily with the real Executor; use valid real two-direction CRN evidence before selection if genuine adapter is available; share deterministic cache. Mechanism 2 — conflict-directed backjump across reaction boundaries: A FINISH that creates a route ancestor cycle, or a real unresolved AND precursor under exhausted search budget, yields a precise failure dependency. Locate earliest responsible reaction-level electronic decision with actual retained alternative; restore its route and electron checkpoint including pending AND obligations, log-prob lineage and stock leaves; then try saved distinct FLOW before making capped new actor requests. No four-fold repeated FINISH, no made-up new candidate and no incorrect terminal failure label for merely untried branches. Fixed finite search budget and cycle detection.

Mechanism 3 — optional frontier allocation using ONLY actual observed evidence: prefer a completed route proof, real chemically supported FINISH, real inventory discharge, distinct verified chemical successor and authentic local CRN score; never substitute speculative learned value for unexecuted chemistry. Do not require monotonically decreasing molecular complexity: real natural-product routes need preparatory steps. Keep this component ONLY if it adds meaningful matched-budget gain beyond mechanisms 1+2. Existing ReFIT-PO route credit remains a separate learning mechanism; do not confuse inference selection with on-policy same-state GRPO.

The core innovation hypothesis: branching before commitment of a reaction exposes strategically different chemical routes unavailable or prohibitively expensive with complete-reaction-first search, while conflict-directed route feedback makes these electronic branches useful for real AND/OR synthesis. Explicitly compare to ordinary PUCT, MCTS, Retro* and reaction-first baseline: do not claim novelty of a generic search tree or backtracking in isolation.

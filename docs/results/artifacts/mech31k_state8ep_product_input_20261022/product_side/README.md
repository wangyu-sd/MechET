## Exact condition and limits of the claim

This reuses the same 32 **validation** reactions as the preceding next-action
teacher-forcing diagnostic. It is not the full 3,120-reaction test set.

The input is the frozen trace-view **product side**, not an isolated major
product: all 32 inputs have two molecular components. Smaller components are
15 chloride ions, 10 `[OH2+]B(Br)Br`, 3 bromide ions, 2
`CC(C)(C)OC(=O)[O-]`, 1 iodide ion, and 1 `CC(C)(C)[Si](C)(C)F`.
These components are in the source `target_smiles` / `source_product_reference`;
they are not generated by the model. Do not report this result as strict
single-major-product-only accuracy, or compare it directly with the historical
full-3,120 `rxn_prod_min` input condition.

Original atom-map IDs are removed; the public product side is independently
remapped. The checkpoint is **Stage-I state-only**, so observations contain the
current state but no compressed history. This matches this checkpoint's training
contract; it is not the compressed-history Stage-II model.

GT trajectories span 1–5 electron events and 2–7 tool calls, including IMPORT
and FINISH. This tests a complete single-reaction electronic trajectory, not a
multi-reaction synthesis route or unrestricted long-horizon planning.

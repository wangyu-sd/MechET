# Three source-checked analogues with unresolved applicability

These are actual frozen indexed candidates selected after inspecting model
outputs. They are **not independent policy-calibration controls**, new model
experiments or chemically proved negative examples. Original TierC grades
remain unchanged. Each actual primary procedure, short unique witness and
named source structure is bound to raw/text/normalization/receipt hashes in
`source_scope_review.json`; no full patent is redistributed.
`review_bindings.json` separately binds all three query/candidate pairs to
the actual v9 analysis, frozen local-family keys and component-multiplicity
checks. It does not turn those descriptor matches into compatible chemistry.

All three candidate/query pairs match the frozen radius1 full-stereo local
reaction-family descriptor. Independently transcribed source covalent products
and essential substrates agree with the extracted candidate; known Na/water
components are explicitly identified rather than silently added/removed from
the original retrieval record. The primary source adds further context that
this local descriptor alone cannot settle:

substrate, its ionic environment or every symbolic inverse FLOW arrow.
The corresponding original queries, raw candidate structures, known component
roles and unresolved decisions are retained in the bound records.

These reviewed records are deliberately **not added as positive or negative
overrides to the population evidence registry**. No TierB/D or new supported
target count is inferred from this post-hoc inspection. Broader analogue
review and independent precision/recall calibration remain incomplete.

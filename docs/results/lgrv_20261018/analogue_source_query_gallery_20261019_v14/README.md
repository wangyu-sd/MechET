# Performed sources versus generated analogue reactions

All6 newly reviewed TierB pairs are drawn on3 RDKit plates. Each top row is
the actual performed source;the lower rows are genuine frozen model-generated
complete reactions with explicit **analogue inference,not performed experiment**
labels. No source yield is assigned to a generated query. Full substrate
differences,compatibility rationale andlimits are in the
[18-pair source review](../grouped_primary_review_20261019/README.md).

The first plate shows two different Br/boronic-acid handle assignments reaching
the same biaryl. They are different complete precursor sets,not two independent
experiments. This demonstrates the generated disconnection alternatives;it
does not establish equal yield,route superiority or matched-compute gains.

All3 actual PNGs were opened and inspected for source/query distinction,
coupling sites,retained functional groups/stereochemistry,labels andclipping.
All9 SVG/PDF/PNG exports passed vector/font/183-mm/maximum-height/300-dpi QA.
[The manifest](figure_manifest.json) binds each source/query graph,all pair
reviews,full source conditions and source/producer hashes. Earlier figures
are preserved. These forward-oriented net schemes do not depict experimentally
verified microscopic electron arrows;actual saved FLOW diagrams remain in
the separate program/case figures.

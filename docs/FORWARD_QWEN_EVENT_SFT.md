## Data and direction

Use the original `flower_new_dataset/{train,val,test}.txt` forward transitions,
not model-generated reverse trajectories. Eligibility comes from the frozen
strict-proof reaction IDs: 257,167 / 2,890 / 28,967. This is **not** the
257,171 / 2,890 / 28,971 official endpoint universe; the only eligibility
restriction is the existing named corrupt-upstream exclusion. No new chemistry,
deduplication, overlap or length filtering is permitted.

Each row supplies the current mixture and temporary inventory, optionally with
the recorded accepted path history. It never supplies the future state or final
product in a policy input. A forward source-to-destination BE delta is encoded
as a canonical replay-exact electron-pair witness, or explicitly as BE_DELTA
where unique pairwise arrows cannot be established. These derived arrows are
not claimed to be uniquely identified experimental elementary mechanisms.
All explicit source hydrogens are retained without choosing them using the
gold reaction centre. The full mixture is known at the beginning of a forward
reaction; it is not generated by an upfront inverse-fragment decoder.

`apply_forward_electron_flow(direction="forward", ...)` resolves current
temporary names and runs the existing executor. `finish_forward()` returns the
current product mixture. Recorded self-loops supervise termination. Reference
replay must match the recorded next state including maps. Any unresolved row
keeps the complete artifact training-disabled, rather than being dropped.

### October 16 processing corrections

Raw records are grouped by trajectory ID across the entire source file, not
by adjacent runs: validation alone contains 17 interleaved IDs. A byte-range
index preserves every repeated row, first-occurrence reaction order, and
within-reaction export order without retaining the multi-GB training text.
The export order is not execution order. Histories follow one deterministic
recorded root-to-state graph path, never a concatenation of alternative
branches. `history_decision_indices` retains provenance; unrooted states are
reported as errors rather than silently relabelled as initial states.

Before generating temporary aliases, both training and forward execution
canonicalize the **current private mapped graph** with explicit hydrogen
nodes retained. This prevents identical reagent copies from swapping private
identities after an executor SMILES round-trip. It uses no future state or
target to normalize the input. Shared inverse serialization is unchanged.

## Inference after training

Initialize a proposed complete reactant mixture with `initialize_forward_state`,
which adds explicit hydrogens and assigns private maps from that mixture alone.
Repeatedly show only the
actual current state and accepted forward history, execute the sampled event,
and stop on `finish_forward` or a declared budget. Compare the final principal
organic product with the target **outside** the policy prompt. This enables a
blind forward round-trip test, but chemical correctness or improvement has not
yet been measured. A separate matched full evaluation is not part of this
training submission.

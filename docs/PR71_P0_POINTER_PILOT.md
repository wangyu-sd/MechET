# PR #71 P0 electron-flow pointer pilot

This is the first **gated** experiment from the vNext roadmap, not an implementation of its tree search, long-horizon credit assignment, or distillation stages. The frozen Stage-II v2 Qwen3-8B adapter supplies contextual representations; a separate source/sink head learns to localize electron transfers in the currently visible molecular inventory. The base and Stage-II adapter remain frozen. No endpoint or executable-trace improvement is claimed until a later integrated policy experiment proves it.

## Data and contract

- Input: the exact Qwen Stage-II v2 tool-call prefix generated by `render_qwen_sft_tool_prefix`; current state and accepted-action history are visible. The target tool call and tool result are omitted.
- Targets: every source and sink in the gold `apply_electron_flow` decision. Import and finish decisions do not have pointer labels and are excluded **only from this localization objective**, not from the original Stage-II SFT.
- Candidate source sites: current atoms and existing bonds. Candidate sink sites: current atoms and all unordered atom pairs (including bonds not yet present). These are structural candidates, not an assertion of chemical feasibility.
- Train: 19,199 event decisions from 10,152 current-compiler executable reactions. Validation: 2,543 event decisions from 1,319 reactions. These are not the full 24,959/3,120/3,120 reaction-level mech-USPTO benchmark.
- Training uses a multi-target cross-entropy over all moves in an event. Report source/sink Recall@1/4/8 and all-target Recall@8 on the full validation event split. No test labels enter training or model selection.
- The backbone is Qwen3-8B revision `b968826d9c46dd6066d109eabc6255188de91218`, with the completed 31k Stage-II v2 adapter. Candidate embeddings are taken at the final token of each `<Axx>` inventory marker; a global query comes from the SFT-aligned assistant prefix.

## Training command

On one 8×A100 Taiji host, use `scripts/run_taiji_pr71_pointer_8a100.sh` through `scripts/taiji_run_with_heartbeat.sh`. The script verifies GPU identity, validated data manifests and hashes, reaction split separation, parser coverage, checkpoint existence, and Qwen revision before training. It logs every 20 rank-0 updates to POD stdout and writes a full validation report plus pointer weights under `outputs/agent/pr71_p0_pointer_31k_stage2_8a100_20261001/`.

Promotion gate: compare full-valid source/sink Recall@K to a frozen zero-training baseline, then integrate pointers into constrained action decoding and measure strict event/endpoint performance under identical product-start inference. A pointer-only metric is not a retrospective synthesis result.

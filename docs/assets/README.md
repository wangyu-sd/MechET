# Brand assets

`mechet-icon.png` is the repository icon displayed in the project README. It is a lightweight 384 × 384 transparent PNG derived from the user-supplied artwork and optimized for GitHub rendering at 168 px.

The design combines a molecular scaffold, an integrated `M`/`E` monogram, curved electron-flow arrows, and electron symbols to reflect MechET's trace-owned electron-transfer formulation.

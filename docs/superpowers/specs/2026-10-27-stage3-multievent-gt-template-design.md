**决策更新（2026-10-27）：第三阶段的主要对齐对象改为跨反应的完整多步逆合成路线。此前仅针对“单个反应内多个电子事件”的设计不再是主目标。**

## 一、为什么必须区分两种“多步”

原 PR #98 提出的“完整后缀策略梯度 + GT 轨迹监督 + 原作者机理模板”有明确价值，但其原定义中的多步仅指同一反应中连续多次 IMPORT/FLOW/FINISH 电子决策。FINISH 结束的是**一条逆向反应**，不意味着多步逆合成已完成。

这里重新固定研究任务：

- **内层：单次反应的逆向电子流程序。** 给定当前待拆解分子，模型按原有产物输入、真实执行状态和压缩历史，连续执行 IMPORT、FLOW、FINISH，得到完整结构前体集合。每个反应内部的电子事件仍必须形式执行，并保留全部原始记录。
- **外层：多步逆合成路线的前体义务。** 每个 FINISH 产生一条“产物 → 所有结构前体”的反应边。对未在指定购买库的每个前体继续开新反应，直到所有义务叶节点均在冻结原料库中，且至少存在一条非零步模型生成反应。
- **训练结果：路线级闭合回报。** 第三阶段把这一条完整路线（而非单反应一次 FINISH）的成败反馈给全路线参与决策的模型动作。
- **测试结果：stock-connected Solved@Budget。** 单反应 exact-match、FINISH 率、电子后继一致性仍同时记录，但不能替代路线规划效果。

电子流动作数 ≠ 合成反应步数；前者位于内层，后者是外层路线的反应边数。完整路线是 AND-闭合的反应超图，不能只让其中一条可购买前体分支到达 stock 就宣布解决。

## 三、训练样本如何构造：严格 TRAIN-only，多步为真

**主张不新增全新的反应数据集**：优先用现有 FlowER 与 mech-USPTO-31k 的 verified TRAIN 电子反应和原 R1 采购库，构造可审计的训练路线任务；对两个数据集分别冻结父模型和分母，不未经许可混训。

- 现有 PR96 电子参考训练范围分别为 mech-USPTO-31k 10,137 个 source-arrow accepted TRAIN 反应、FlowER 243,753 个 source-arrow accepted TRAIN 反应；这些不是公开全集全部反应。继承原始隔离/源哈希，不为保证正例而偷换分母。
- 从 TRAIN 内每条已核验反应提取“结构前体集合 → 产物”的关系与逐反应真实电子程序。以带版本的化学身份键连接：某反应的未在 stock 的结构前体如果确切等同于另一条 TRAIN 反应的产物，可组成一条来源可追溯的多反应路线；盐、带电片段、手性、同位素、组分多重性都要如实保留；禁止用未核验的原子映射差异推导源-受体电子步骤。
- 训练样本只有当每条合成反应边可溯源、全部义务能闭合到指定 stock 时，才能作为“可核验的路线监督案例”；否则只能作为路线级在线 RL 的待解目标，不可伪造 GT 全路线。
- 可从 TRAIN 产物中选根目标，预先剔除冻结的 460 个 R1 评价目标及必要的身份/反应边重叠；来源于 RetroCast/PaRoutes 的路线定义仅按各自预先固定的训练/验证/测试划分使用，不能把当前 460 目标的参考路线、终点标签或 MCTS 搜索证据回灌到策略优化、偏好构造或训练起点挖掘。
- 在正式实施前输出 **多步 TRAIN 可构造性审计**：可闭合路线根目标数、实际深度≥2 数、每步原始电子程序覆盖率、stock 版本、无法联接原因、测试重叠清单。若多步 TRAIN 支持不足，诚实说明无法直接开展有意义的路线级 GT 监督；不要通过人为插入不存在的反应或拿 460 个评测目标训练来补足。
- 短路线/单步样本只能保留为课程与基础能力维护项。真正用于证明多步优化的训练和测试必须另外报告参考深度与**实际生成路线反应步数**，防止被大量容易单步到货的目标占据回报。

## 四、路线级在线 RL：从一个根目标到完整 AND-route 的真实采样

### 4.1 采样层次

一个训练 episode 从指定产物、冻结原料库和空的路线义务集合开始。外层调度器从当前待拆解分子中选择一个继续处理；内层 Qwen3.5-0.8B 策略在该分子的真实电子状态上生成完整 IMPORT/FLOW/FINISH 程序。FINISH 后把所有结构前体加入路线义务，未在原料库的前体继续递归；直到 **全部叶节点 stock-closed** 或真实预算/停止条件出现。

主要策略仍为 **一个 Qwen electron actor + 原有执行器**。不新增 backbone、图网络或独立 value model。原有外层调度器可先冻结为算法环境；必须明确它是否是随机的、其搜索选择有何概率，并把行为轨迹完整归档。原策略提示中只有当前反应的公开状态和压缩历史；若后续想加入“剩余前体义务/当前 stock 查询”等**合法公开路线状态**，那是新的输入协议，需要单独完成训练格式适配和消融，不能直接归到原提示契约成果。

### 4.2 什么轨迹可以算 actor 的 on-policy RL 样本

- 优先使用真正**独立完整路线 episode**做 actor policy-gradient 采样：组内多个样本从同一个训练目标出发，不跨 episode 共享候选电子状态、搜索树决策或采样缓存。组内冻结同一个 actor 版本，每次刷新 actor 都重新采样。
- 记录全路线中每一次模型实际生成的动作 token、实际观测、行为 logprob、受理/拒绝状态、所属反应边和采样版本。对全路线由同一 actor 产生的所有策略 token 进行可追溯、归一化的策略梯度更新（而不仅是一个反应的首动作）。工具回复、执行器输出、GT、参考后缀等必须 mask。
- **不得直接把多叉 MCTS 搜索后“被挑出来的最佳路线”的所有历史动作当作独立 on-policy actor 样本计算普通 GRPO。** MCTS 的自适应选择、重用缓存和分支选择会改变采样分布；若不显式建模行为概率/校正，则只能将符合 TRAIN 来源约束的成功路线作为另一个单独标识的 **offline imitation / replay CE** 来源，而不能伪装为 fresh RL 正样本。
- 可以复用路线搜索器的已审计数据结构、执行器、原料库成员检查、路线证明与日志；采样算法的统计语义不能默默从独立 episode 变成有共享分叉的 MCTS，再对该数据使用独立采样目标函数。

### 4.3 路线回报：最终闭合是主目标，模板只是局部辅助

建议将**主要路线回报**明确为：
- 1：正常完成至少一个真实模型生成的反应，且全部必须的前体义务都通过原 stock 严格成员检查（AND closure）；
- 0：episode 按真实计算预算结束且未找到完整 stock-closed route；
- **未判定**：物理上下文耗尽、作业中断、缺失输出或证据不完整所致的资源删失；不能当成化学失败 0。
- 已在 stock 的零步初始目标**不得**领取“新合成路线成功”奖励；所有环、空变化、重复导入和无化学进展的 FINISH 保留显式失败/诊断。
- 小权重、可审计的辅助成本项可约束无意义超长路线、无效工具调用与明显回路，但不能让“接近库存”“输出更多组分”“更频繁导入片段”替代真实路线闭合。若使用 potential shaping，必须证明不改变主任务成功偏好并单独消融。

同一根目标多个真实独立完整 episode 的**组相对 clipped actor loss**，以完整路线回报计算优势，并分配到该路线所有实际采样电子决策。按**路线/目标先归一化，再在有效动作上归一化**，避免长路线或长 token 无故占更大梯度。保留固定父权重 KL，参考策略不得偷看训练后权重。

全失败或全成功组缺少组内相对优势，日志必须报告 **有效优势组比例**，不得从 GT 直接混入“成功的策略样本”。若路线闭合奖励在训练任务上几乎无正样本，必须据实停止路线 RL 有效性归因，使用合法的 GT 监督训练稳定性，不能把 CE-only 更新描述为 route RL 已学会。

### 4.4 GT、模板三种信号独立记账

主目标：真实 stock-closed 完整路线回报 RL。

GT 监督：对 verified TRAIN 中有真实事件标注的各反应执行 **完整多电子事件监督**；若有经过上节验证的连续多反应真实 GT 路线，可以另外增加 GT route-prefix imitation；如果没有，不得宣称“多步路线 GT 监督”。CE 的反应计数、route 数、实际监督 token、与 RL 采样样本必须分开统计。训练 GT 提示只能包含当前合法公开状态与真实已完成前缀，不给未来动作、路线目标答案或测试 GT。

模板辅助：冻结 PR #90 审计过的 FlowER 作者模板，逐事件检查逆 s→s' 的正向 s'→s 转移，检查完整映射、氢/电荷/芳香/自由基并保留单规则与组合规则区别。其已观测匹配率不代表独立化学真值，尤其不能等同地推广到 mech31k。**默认先作为离线/在线诊断，不直接加入有梯度的模板奖励**；后续只有预注册正负证据规则和消融验证，才允许很小、有界、不计重复次数的过程辅助项。模板不匹配=未知，不是化学错误；不因带电自动判错，也不因为模板可匹配就认定合成实验可行。

概念上可拆为：全路线策略损失 + 固定参考 KL + 独立 TRAIN 电子轨迹 CE + 可选经验证模板辅助。各项分别记录覆盖、贡献、消融与权重，不把监督损失计作 RL。

- 资源预算是物理训练工程要求；真实 FINISH、循环、无效操作、无法扩展与资源删失是不同科学终止类别，禁止把预算消耗视为完成合成的正证据。
- 所有来源样本、行为策略 SHA、GT 与模板源版本、原始 I/O、逐步状态与路由证明、完整奖励构造、optimizer/checkpoint 游标保存到当前授权存储目录（按实现时冻结绝对路径，不在本设计稿创造新 Ceph 路径）。

## 六、评测直接同时服务 R1 多步搜索与 R4 后训练

必须拆开**训练是否有效**与**搜索是否有效**，不能把有更大预算的搜索误称为后训练收益。

提出四路 2×2 主对照，在完全相同公开产物、stock、目标 ID、模型生成预算和 executor 语义上：

| 冻结 actor | 不使用树搜索的单路线/独立采样 | Reverse electron-flow tree search |
|---|---|---|
| Stage-II parent | Stage-II + independent K | Stage-II + Tree |
| 新路线级 Stage-III | Route-RL + independent K | Route-RL + Tree |

- **R1** 的搜索算法增益：在**同一 actor**、同预算下比较 Tree vs Independent K。
- **R4** 的路线级后训练增益：在**相同搜索方式与预算**下比较 Route-RL vs Stage-II。
- 两种增益不可混写；如同时变化 actor 和搜索，单独报告交互项，不将全部提升归因于其中之一。
- 460 个既定路线基准（Expert 100、Drugs 100、RetroCast 160、PaRoutes-derived 100）**只能用于冻结评价**；各组 stock 和评价规则保持原样，仍须补齐未完成或删失输出，不能对可成功的 200 个目标选择性报率。
- 完整 Solved@B、随 token/执行调用变化的发现曲线、深度 2/3/4/5 的分层表现、独特完整路线数、合成步骤数、模型/执行时间、paired target bootstrap CI，以及真实化学边的兼容性分别统计。
- 单反应结果：保留 31k 的 1,319 VALID、1,253 strict TEST 与完整 3,120 endpoint TEST 的独立人口定义；保留 FlowER 2,890 VALID、28,971 full TEST 的结构/完整混合物定义。不能拿 1,319 VALID 73.62% 与历史 ICLR 28,971 TEST Top-1 相减宣称路线级改进。

## 七、最小必要消融与实质性成功定义

预先设定、同等有效训练开销：
1. Stage-II parent，无 Stage-III；
2. 原 PR #97 first-action EARHO（按其真实旧 checkpoint/合同）；
3. 新整条**单反应后缀** RL + GT CE（只证明局部训练改变）；
4. 新整条**多反应路线** RL + GT CE（本方案主要结果）；
5. 若模板辅助启用，单独比较“模板诊断不参与梯度”与“小权重可信模板项”。

注意 3、4 中相同 actor 与计算预算的对照才可隔离跨反应训练目标的增益；旧 PR #97 的结果只是已存在的历史证据，不能无条件与新 0.8B 多步测试数值直接拼成 matched ablation。

**验收门槛：** 有真实 TRAIN-only 多步任务；采样确实跨越≥2条真实模型生成合成反应边；策略梯度真实覆盖多个反应中的电子决策；路线回报依赖所有结构前体叶节点；任何正例不来自 460 个评价目标的参考或缓存；并在同预算完整路线评测中证明提升。否则报告“只完成单反应 trajectory RL 或训练准备”，不得称路线级对齐已完成。

**Phase B（协议和代码设计）：** 设计跨反应完整独立 episode 的原始日志、行为 logprobs、路线 AND 终点、route-token policy gradient、GT CE 及模板诊断；在 CPU fixture 检验无参考泄露、全部叶节点、负例与删失、token mask、等价路线、离子和恢复一致性。软件测试不作为实验增益。

**Phase C（真实训练，需用户授权）：** 在各数据集原 Stage-II 父模型单独实现第三阶段，保存完整透明的训练日志；不自动启动新 GPU/太极任务、不打断现有 PR #97 作业。

**Phase D（正式评价）：** 相同目标、stock、预算的 2×2 RouteRL×Search 控制及单反应能力保持；结果来源绑定到新 Figure 2 / R4，缺项继续标为 PENDING，绝不补预计值。

本轮用户已确定的重要科学取舍是：**第三阶段直接面向跨反应的多步逆合成，而不是仅将单反应内的电子序列加长。** 其他超参数（独立 rollout K、根/合法路线前缀比例、token 成本阈值、KL/GT 权重、模板诊断晋级阈值）需先由 TRAIN 真实支持与计算成本审计给出冻结值，不能在方案阶段臆造已验证的最优数值。

方法背景：DeepSeekMath/GRPO、DAPO 可作为路线 group-relative policy update 的方法参考，但并不证明在该化学任务上路线级奖励稀疏性、长路线信用分配或模板辅助必然有效。

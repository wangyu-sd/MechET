## Agent and memory boundaries

The actor proposes reverse electron-flow/import actions. The executor owns authoritative state. FINISH marks one reaction endpoint; productive-change/cycle/contributor-stock checks decide commit, then unresolved structural precursors start fresh reaction occurrences. MCTS remains the planning controller; continuous route-RL episodes are a distinct on-policy collector and must not be advertised as MCTS.

The current ExperienceMemory API uses exact execution+history scope and hash-bound completed TRAIN verifier receipts. It is not yet a transferable strategy retriever. The next integration must expose memories as data, never execute stored atom handles, retain all rejected attempts and bind each rendered memory version to durable samples. A resource interruption is not a chemical negative. Memory utilities are empirical retrieval feedback, not learned chemical validity or policy advantage.

Two update loops: fast CPU memory curation with frozen weights; slow verified replay/policy updates. Neither loop mutates the executor/stock oracle to improve scores. Evaluate closed-target yield, validated route quality, repeated failures and GPU time per solved target under matched budgets.

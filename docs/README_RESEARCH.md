# README research summary

The MechET front page was redesigned after reviewing widely adopted paper repositories in computer vision, generative modeling, protein modeling, and AI for science.

Recurring patterns used in the redesign:

- one decisive contribution statement above the fold;
- a runnable example before the paper-reproduction pipeline;
- visible CI and honest artifact-availability status;
- separate user quickstart, training, evaluation, data, citation, and limitations;
- detailed method material linked from `docs/` rather than copied into the landing page;
- legacy implementations kept available but visually secondary;
- no pending or known-wrong experimental numbers in the public results area.

For MechET, the resulting primary storyline is:

```text
mapped product -> executable MECH_PROOF v1 -> deterministic executor -> precursor
```

`MECH_ET v3` remains a compatibility and cold-start compilation path.
